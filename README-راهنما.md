پولیتو (Polito) — بسته تخت پروژه

اصل مهم
- index.html از فایل مرجع کاربر ساخته شده و کدها/کلیدهای ذخیره‌سازی قبلی حذف یا تغییرنام داده نشده‌اند؛ قابلیت‌های جدید به‌صورت افزوده اضافه شده‌اند.
- index-reference-original.html نسخه اصلی برای مقایسه و بازگشت است؛ هنگام انتشار سایت، فایل index.html را به‌عنوان صفحه اصلی منتشر کنید.
- فونت Vazirmatn برای متن‌ها و کنترل‌ها یکپارچه شده است. این فونت در حالت فعلی از Google Fonts دریافت می‌شود و به اینترنت نیاز دارد.
- بخش بروزرسانی نسخه و تغییرات را از version.json می‌خواند. بروزرسانی وب پس از انتشار فایل‌های سایت، داخل WebView اندروید هم بدون نصب مجدد APK نمایش داده می‌شود. تغییرات بومی Kotlin نیازمند ساخت APK جدید است.

انتشار وب در GitHub Pages
1. index.html و version.json و service-worker.js و manifest.webmanifest را در ریشه مخزن سایت قرار دهید.
2. منبع GitHub Pages را روی شاخه موردنظر و ریشه (root) تنظیم کنید.
3. در هر انتشار، شماره version در version.json و مقدار CURRENT_VERSION داخل index.html را هماهنگ کنید و توضیحات تغییرات را در changelog بنویسید.
4. داده‌های قبلی localStorage با تغییر کد یا انتشار نسخه حذف نمی‌شوند. از بخش تنظیمات می‌توان فایل پشتیبان گرفت. داده‌های مرورگر با داده‌های WebView اندروید یکی نیستند؛ برای انتقال بین آن‌ها از پشتیبان‌گیری/بازیابی استفاده کنید.

آماده‌سازی Android Studio و GitHub Actions
این ZIP عمداً تخت است و هیچ پوشه‌ای داخل آن نیست. اما Android Studio و GitHub Actions برای Build به ساختار استاندارد Android و مسیر .github/workflows نیاز دارند.
1. ZIP را استخراج کنید.
2. Python 3 را نصب داشته باشید و در همان پوشه اجرا کنید: python3 prepare_android.py (در ویندوز معمولاً: py prepare_android.py).
3. اسکریپت، پوشه‌های لازم را می‌سازد و فایل‌ها را در مسیرهای استاندارد کپی می‌کند؛ فایل‌های تخت ریشه را حذف نمی‌کند.
4. پوشه پروژه را در Android Studio با Open باز کنید.
5. برای GitHub Actions، فایل‌های آماده‌شده را به مخزن push کنید؛ workflow در .github/workflows/android.yml قرار می‌گیرد و APK آزمایشی را می‌سازد.
6. آدرس سایت برنامه در MainActivity.kt مشخص شده است: https://farrokh992-eng.github.io/TestHamid

نکته مهم درباره استقلال و بروزرسانی
- برنامه اندروید فعلاً یک پوسته WebView است و سایت منتشرشده را از اینترنت بارگذاری می‌کند؛ بنابراین تغییرات سایت بدون دانلود APK جدید قابل مشاهده است.
- این به معنی بروزرسانی خودکار کد بومی Android نیست. برای تغییرات Kotlin یا مجوزها باید APK جدید ساخته و توزیع شود.
- ساخت APK در این محیط اجرا نشده است؛ فایل workflow از نظر ساختار YAML بررسی شده، اما Build واقعی باید در Android Studio یا GitHub Actions انجام شود.
